#  ドブ捨てマネー報告書 〜サブスク未使用編〜

使ってないサブスクをNISAに回してたら？ 放置サブスクの損失額を診断するWebアプリです。

 https://subscrib-one.vercel.app/

※エンタメ目的の簡易シミュレーションで、投資助言ではありません。

## 概要

月数百〜数千円のサブスクは危機感が湧きにくいため、長期の複利で見た損失額を可視化し、解約のきっかけを作ることを目的に制作しました。

## 主な機能

- 年齢・月額合計・放置歴から、年利5%(月複利)で87歳まで運用した場合の損失額を診断
- 損失額に応じた5段階のランク判定とコメント表示
- Xでのシェア、Amazonアフィリエイトリンクへの導線

## 使用技術

HTML / CSS / JavaScript(フレームワーク不使用)、Google Fonts、Vercel

小規模な1画面のアプリのため、ビルド不要の素のJavaScriptで実装しました。

## 工夫した点

- 入力・計算中・結果の3画面を、ページ遷移なしで切り替え
- ランクごとに背景色を変え、コメントや行動提案をランダム表示して、結果に変化をつけた
- 年齢の入力チェックと、スマホ対応(viewport設定、数字キーボード)

## 今後の改善点
